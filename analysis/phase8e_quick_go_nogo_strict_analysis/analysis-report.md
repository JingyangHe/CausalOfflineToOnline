# Phase 8E-Q 严格只读结果分析

## 结论与决策

本次 quick gate 的科学结论是 **No-Go**：当前结果不支持扩大到完整 Phase 8E，也不支持继续做连续动作扩展。

这不是因为实验实现失败。原始结果的 23 项硬检查全部通过，10 个场景、90 个 best-only 模型、512 个固定 anchors 以及全部指标均完整可读。失败发生在科学假设层面：正确 source 标签没有稳定优于 source shuffle；五个多样来源没有优于两个多样来源；五个冗余来源也没有表现出预期的劣势模式。唯一清楚且跨三个模型 seed 一致的收益来自干预校准预算，而该收益同样出现在不使用多来源 rank-1 对比的 pooled rank-0 基线中。

因此，当前实验支持的更窄结论是：**少量干预样本能大幅改善三动作的一步决策，但现有多来源对比表示没有在这些样本之外提供可验证的额外信息。**

## 分析对象与统计口径

实验使用 512 个 anchors，固定拆分为 333 个训练、51 个观测验证、51 个干预校准池和 77 个最终测试 anchors。每个模型 seed 内的 5 次校准重复共享同一模型和同一数据生成过程，因此先在 seed 内求均值，再以 3 个模型 seed 作为独立比较单位。所有比较均为配对比较；报告配对均值差、样本标准差、t 型 95% 区间和对 (2^3=8) 种符号翻转的精确双侧检验。由于只有 3 个独立 seed，最小可达双侧精确 p 值为 0.25，本报告不作确认性显著性声明。

## 四个预注册式主问题

以下均为 λ=0.05、confounded、B=64 的左侧减右侧差值；三个指标都是越低越好。

| 比较 | Do-MAE 差 | 排序错误差 | Regret 差 | 种子方向 | 判断 |
|---|---:|---:|---:|---|---|
| Correct source − Shuffle | +0.001163 (+3.14%) | +0.006061 (+1.58%) | +0.000004 (+0.30%) | 三项均混合 | 不支持正确 source 更好 |
| M=5 diverse − M=2 diverse | +0.002858 (+8.09%) | +0.002597 (+0.67%) | +0.000060 (+4.71%) | MAE 为 3/3 更差 | 不支持更多来源更好 |
| M=5 redundant − M=5 diverse | −0.003100 (−8.12%) | +0.042424 (+10.87%) | +0.000078 (+5.85%) | 指标彼此冲突 | 不支持预期冗余对照模式 |
| B=64 − B=0 | +0.001803 (+4.96%) | −0.514286 (−56.84%) | −0.004117 (−75.43%) | 排序与 regret 均 3/3 改善 | 校准改善决策，但不改善 Do-MAE |

12 个主检验的 Holm 校正 p 值均为 1.0。这里不应把“不显著”简单解释成“完全相等”：更重要的证据是 correct-vs-shuffle 的效应很小且种子方向不一致，而 M=5-vs-M=2 的 Do-MAE 在三个种子上都朝不利方向变化。

## 干预校准到底学到了什么

M=5 diverse、correct-source 在 B=0、16、64 时的均值如下：

| 预算 | Do-MAE | 排序错误 | 一步 regret |
|---:|---:|---:|---:|
| 0 | 0.036374 | 0.904762 | 0.005458 |
| 16 | 0.044223 | 0.561905 | 0.002299 |
| 64 | 0.038177 | 0.390476 | 0.001341 |

从 B=0 到 B=16，排序错误下降 37.9%、regret 下降 57.9%，但 Do-MAE 上升 21.6%。从 B=16 到 B=64，三个指标均改善；相对 B=0，B=64 仍然只改善决策指标，未改善整体奖励点预测。

更关键的消融是 B=64 时 adaptive 与 pooled rank-0 的比较。Correct-source 相对 pooled 的 Do-MAE 更差 0.003310（3/3 seed 更差），排序错误只低 0.012121，regret 只低 0.000004。Shuffle 相对 pooled 也呈现几乎相同的模式。因此，B=64 的主要收益可以由三个动作各自的低维校准系数解释，不需要 source-dependent rank-1 分支。

## 机制审计：真实信号存在，但没有转化成收益

数据生成机制本身通过了关键阳性和阴性对照。在 λ=0.05、confounded 条件下，minus/plus 动作的总体 source contrast 严格为 rank 1：M=2 的领先奇异值为 0.5543，M=5 diverse 为 0.6197；base 动作为零。M=5 redundant 和 independent-latents 的总体 source contrast 也均为零。因此不能把 No-Go 归因于“DGP 根本没有制造多来源因果信号”。

问题出现在有限样本恢复阶段。固定总观测预算后，M=2 每个 source×anchor×action 训练单元平均有 21.33 条记录，而 M=5 只有 8.54 条，减少约 60%。M=5 diverse 的经验矩阵 rank-1 残差占 centered norm 的 60.6%–61.6%；在 base、redundant 和 independent 阴性对照中，该比例约为 84%–86%，表明有限样本噪声本身会制造很强的高维 source 结构。M=2 的经验残差为零主要是代数事实：两个来源中心化后至多 rank 1，不能证明其 source signal 更干净。

神经网络确实拾取了一点正确 source 信息：未经干预标定的 rank-1 contrast RMS，correct-source 为 0.01405，shuffle 为 0.00879，correct 高约 60%。但 source reconstruction MAE 几乎相同（0.03459 对 0.03474），且这点表示差异没有转化为更低的 Do-MAE、排序错误或 regret。

BIC 的 rank-1 选择也没有区分阳性信号和空信号：

| 场景 | B=16 | B=64 |
|---|---:|---:|
| λ=0.05 confounded, correct | 3/15 (20.0%) | 2/15 (13.3%) |
| λ=0.05 confounded, shuffle | 3/15 (20.0%) | 2/15 (13.3%) |
| λ=0, correct | 4/15 (26.7%) | 3/15 (20.0%) |
| independent latents, correct | 1/15 (6.7%) | 1/15 (6.7%) |

阳性场景的 rank-1 选择率与 shuffle 完全相同，甚至低于 λ=0 空信号场景。这是当前多来源分支未产生增益的最直接诊断证据。

## 阴性对照与安全性

λ=0 时，correct-source 没有可靠回到 pooled rank-0：B=16 的 rank-1 误选为 4/15，并且相对 pooled 的 Do-MAE、排序错误和 regret 分别恶化 11.2%、17.2% 和 8.5%；B=64 时差异缩小，但仍有 3/15 次选择 rank 1，且三个指标的 seed 方向均不一致。因此 `lambda_zero_safely_returns_to_rank0` 判据失败是有实质依据的。

Independent-latents 阴性对照中，correct-source B=64 相对 shuffle 的 Do-MAE、排序错误和 regret 分别高 2.4%、13.9% 和 15.1%。样本量不足以确认这些差异，但它至少没有提供 source-aware 模型在零总体对比下更安全的证据。

## 失败归因

证据最符合以下链条：总体 rank-1 source signal 构造正确；固定总预算被分到更多来源后，每个局部单元过稀；经验 source 均值中的高维噪声与真实 rank-1 信号同量级；网络虽学到较大的 source contrast，但 BIC/干预校准无法稳定识别它；最终有效收益退化为普通的动作级 rank-0 校准。

因此，当前主要瓶颈不是模型规模，也不是校准预算完全无效，而是 **多来源对比的有限样本可识别性与选择功效不足**。直接扩大完整网格只会更精确地重复当前失败模式。

## 建议

1. 不运行完整 Phase 8E formal，也不进入连续动作扩展。
2. 若继续研究，先做一个更小的功效诊断：保持 M=2/M=5 每个 source×anchor×action 单元样本量相同，而不是保持总样本量相同；检查 correct-vs-shuffle 和 BIC 阳性/阴性选择率能否分离。
3. 把 pooled action calibration 明确列为主基线，并单独报告 rank-1 分支在 pooled 校准之上的增量收益。
4. 在增加 seed 前先提高阳性场景的 rank-1 检出率；否则增加 seed 只会提高对零增量收益的估计精度。

## 适用范围

结论只适用于当前 quick gate：κ=0、三离散动作、一步奖励、512 anchors、固定总观测预算、3 个模型 seed。它不直接否定长期回报中的多来源价值，也不否定更高每来源样本量、不同正则化或不同选择准则下的可能收益。
